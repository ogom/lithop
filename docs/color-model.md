# CMYWの色モデルと積層構造

Lithopは、Cyan、Magenta、Yellow、Whiteの4材料を積み重ね、カラーリトファンの色と明暗を表現します。Blackや中間色のフィラメントは使いません。

## 使用する材料

| チャンネル | 製品名            | カラーコード | 表示色（RGB系HEX） | CMYK（Japan Color 2001 Coated） | Extruder |
| ---------- | ----------------- | ------------ | ------------------- | -------------------------------- | -------: |
| Cyan       | PLA Basic Cyan    | 10603        | `#0086D6`           | C: 85%, M: 45%, Y: 0%, K: 0%    |        1 |
| Magenta    | PLA Basic Magenta | 10202        | `#EC008C`           | C: 0%, M: 97%, Y: 0%, K: 0%     |        2 |
| Yellow     | PLA Basic Yellow  | 10400        | `#FCE300`           | C: 3%, M: 9%, Y: 95%, K: 0%     |        3 |
| White      | PLA Basic White   | 10100        | `#FFFFFF`           | C: 0%, M: 0%, Y: 0%, K: 0%      |        4 |

材料表の表示色はRGB系のHEX（16進カラーコード）であり、隣の列にJapan Color 2001 CoatedでのCMYK変換値を併記しています。いずれも画面や印刷物で材料を識別するための色値で、フィラメントの透過色や光学特性を表すものではありません。通常のJPEG、PNG、SVG入力はsRGBからCMYへ変換します。ただし、入力sRGBが表示色と完全に一致する場合は材料チャンネルの指定値として扱い、`#0086D6`はCyan 7層、`#EC008C`はMagenta 7層、`#FCE300`はYellow 7層へ割り当てます。表示色をWhiteで薄めたチャート色の特殊変換は、`data-lithop-color-encoding="material-display"`をルート要素に持つSVGに限ります。未使用の顔料を省略してもExtruder番号は詰めません。

140 mm × 104 mmの`examples/cmy-color-chart.svg`では、ルート要素の材料表示色マーカーにより、横方向の表示色を図中のCMY配合へ割り当て、縦方向の0〜100%を明暗値として扱います。Yellowを含む列だけでなく、Cyan、Magentaおよび混色の列も5%からCMY配合を保持します。平均CMY濃度が4%以下のごく薄い色差をWhiteのノイズとして除去する処理は既定で無効です。`--suppress-pale-colors`または`suppress_pale_colors: true`で有効にできます。暗い無彩色と茶色い細線はCyan 1層、Magenta 1層、Yellow 1層、White 4層へ割り当てます。明暗値は全色列で共通の上部White連続高へ変換し、Y100だけが別の高さ段階にならないようにします。0%は顔料なしのWhiteです。このマーカーは同梱の材料評価用SVGにだけ指定し、一般画像には指定しません。

LED透過確認でYellowが明るすぎる場合は、`yellow_mix_color`と`yellow_mix_percent`でYellow被覆量の一部をCyanまたはMagentaへ置き換えられます。これは材料と光源の組み合わせに応じた任意補正で、既定の0%では無効です。Y100へCyanを20%指定すると目標被覆量はC20/Y80となり、標準7層ではCyan 1層、Yellow 6層が選ばれます。入力RGBとWhite厚さは変えず、CMYWレシピ選択だけを調整します。

## 色の作り方

Cyan、Magenta、Yellowは減法混色として扱います。

- Green: Cyan + Yellow
- Purple: Cyan + Magenta
- Red: Magenta + Yellow
- 暗色: Cyan + Magenta + Yellow
- White: 顔料なし

標準の色領域7層にCyan、Magenta、Yellow、Whiteを配分すると、120個の整数レシピになります。入力sRGBから求めたCMY被覆量に最も近いレシピを選びます。実際の色は材料の透過率、層数、積層順、光源に依存します。

明暗は主に上部Whiteの厚さで表します。厚い場所ほどバックライトを通しにくく、暗く見えます。材料表示色マーカー付きSVGのチャート配合には指定された明暗値を使い、それ以外の入力色はRec.601輝度を反転して画像内の最小・最大で正規化します。White上面は連続高のまま生成し、Bambu Studioへ渡すスライス層高は0.08 mmです。

## 現行の積層構造

モデルは平らな背面をビルドプレート側の`Z=0`に置きます。完成後はバックライトを背面側に置き、凹凸のある`+Z`側から鑑賞します。

```text
+Z / 観察側
┌─────────────────────────┐
│ White: 0.66 mm以上で可変 │  明暗を制御
├─────────────────────────┤
│ CMYWレシピ: 標準7層      │  色相を制御
├─────────────────────────┤
│ White: 下地1層 0.10 mm   │  共通の背面
└─────────────────────────┘
Z=0 / バックライト側
```

### 下地のWhite

最初の1層はモデル全体を支える連続したWhiteです。層高は0.10 mmで、平らなバックライト側の面になります。

### CMYWの色領域

下地の上へ、各0.08 mmの色レイヤーを7層置きます。各XYセル・各高さには4材料のどれか一つだけを割り当て、重複や空洞を作りません。

顔料は既定でバックライト側から`Yellow -> Magenta -> Cyan`の順に並び、残りをWhiteが埋めます。`pigment_order`ではCMY、CYM、MCY、MYC、YCM、YMCの6通りから選択でき、Whiteは常にその後です。

| 表現する色 | 色領域7層の例             |
| ---------- | ------------------------- |
| Cyan       | Cyan × 7                  |
| Green      | Cyan × 3 -> Yellow × 4    |
| Purple     | Cyan × 3 -> Magenta × 4   |
| Red        | Magenta × 3 -> Yellow × 4 |
| White      | White × 7                 |

表は代表例で、入力色により層数配分は変わります。暗い無彩色や茶色い細線にはCMYを各1層重ね、残り4層をWhiteにします。

### 明暗を作る上部White

色領域が終わるZ=0.66 mmから、0.08 mmピッチの上部Whiteを置き、上面を連続高にします。材料表示色と同梱カラーチャートの配合色では指定された明暗値を使い、それ以外の入力色ではRec.601輝度を使います。明るい場所は薄く、暗い場所は厚くします。

`cmy-color-chart.svg`では同じ明暗行にある全13色列を共通のWhite高さへ変換します。YellowのRGB表示色はほかの材料色より明るく見えますが、Y100だけに別のWhite段差は作りません。高さの比較には`preview.png`の見た目ではなく`thickness.png`を使います。

| 領域       | 既定の層数 | Z範囲        |
| ---------- | ---------: | ------------ |
| 下地White  |          1 | 0.00–0.10 mm |
| CMYW色領域 |          7 | 0.10–0.66 mm |
| 上部White  |       可変 | 0.66–1.94 mm |

`--separate-z-parts`では色領域を8層・0.64 mmへ変更します。各プレートの1層目はBase White 0.10 mm、それ以降は共通の0.08 mm積層ピッチです。3分割時のZプレート3はCMYを含まず、強度確保のためBase Whiteを3層・0.26 mmとします。最薄部はTop White 1層を加えたWhite合計4層・0.34 mmです。積層順は[3MFタイル分割とZ分割](tiling.md)を参照してください。

標準の指定厚さと実効厚さは0.74–1.94 mmです。最薄部は下地White 0.10 mm、色領域0.56 mm、上部White 1層0.08 mmで構成し、明るい色の透過を妨げる余分な上部Whiteを置きません。

## 材料別メッシュの関係

材料ごとの形状は、共通座標にある互いに重ならない閉じたメッシュです。Whiteは必ず含まれ、使わないCyan、Magenta、Yellowは省略されるため、3MFの材料部品数は1〜4個です。

Bambu Studioでは一つの親オブジェクトの材料部品として扱います。部品を個別に移動、整列、拡大縮小、結合すると位置関係が壊れます。

## 積層構造の比較結果

4層／5層は比較用に指定できます。標準構造は0.08 mmの7層`Yellow -> Magenta -> Cyan -> White`です。

| 項目   | 標準構造                  | 比較可能な代替構造        |
| ------ | ------------------------- | ------------------------- |
| 色領域 | 7層                       | 4層または5層             |
| 顔料順 | Yellow -> Magenta -> Cyan | CMY、CYM、MCY、MYC、YCM |
| 下地   | White 1層、0.10 mm        | White 1層、0.10 mm        |
| 上部   | 可変厚のWhite             | 可変厚のWhite             |

`--color-layer-count`と`--pigment-order`で比較構造を再生成できます。ローカルUIでは「基本設定」の「色の積層順」から選択します。順序はバックライト側から観察側の向きです。

## 現在の制約

- 未校正時のレシピはフィラメントの実測透過率を使わない
- 入力画像と印刷物の測色的一致を保証しない
- `preview.png`は公称色表示で、印刷物の測色予測ではない
- プリンタ、ノズル、フィラメントロット、光源が変わると発色も変わり得る

測色的一致が必要な場合だけ、[色校正](calibration.md)で実測プロファイルを作成してください。

## 3MFに含まれる情報

`lithop.3mf`には材料別メッシュ、材料名・コード・表示色、Bambu Studio向けExtruder対応、共通座標の組み立て情報が含まれます。

プリンタ、ノズル、AMS実スロット、ビルドプレート、温度、速度、スライスプリセットは含みません。[Bambu Studioでの確認と印刷](bambu-studio.md)に従って設定してください。全成果物は[生成物と記録](artifacts.md)を参照してください。
