# CMYWの色モデルと積層構造

Lithopは、Cyan、Magenta、Yellow、Whiteの4材料を積み重ね、カラーリトファンの色と明暗を表現します。Blackや中間色のフィラメントは使いません。

## 使用する材料

| チャンネル | 製品名            | カラーコード | 表示色（RGB系HEX） | CMYK（Japan Color 2001 Coated） | Extruder |
| ---------- | ----------------- | ------------ | ------------------- | -------------------------------- | -------: |
| Cyan       | PLA Basic Cyan    | 10603        | `#0086D6`           | C: 85%, M: 45%, Y: 0%, K: 0%    |        1 |
| Magenta    | PLA Basic Magenta | 10202        | `#EC008C`           | C: 0%, M: 97%, Y: 0%, K: 0%     |        2 |
| Yellow     | PLA Basic Yellow  | 10400        | `#FCE300`           | C: 3%, M: 9%, Y: 95%, K: 0%     |        3 |
| White      | PLA Basic White   | 10100        | `#FFFFFF`           | C: 0%, M: 0%, Y: 0%, K: 0%      |        4 |

材料表の表示色はRGB系のHEX（16進カラーコード）であり、隣の列にJapan Color 2001 CoatedでのCMYK変換値を併記しています。いずれも画面や印刷物で材料を識別するための色値で、フィラメントの透過色や光学特性を表すものではありません。入力sRGBが表示色と完全に一致する場合は材料チャンネルの指定値としても扱い、`#0086D6`はCyan 7層、`#EC008C`はMagenta 7層、`#FCE300`はYellow 7層へ割り当てます。未使用の顔料を省略してもExtruder番号は詰めません。

140 mm × 104 mmの`examples/cmy-color-chart.svg`では、横方向の表示色を図中のCMY配合へ割り当て、縦方向の0〜100%を明暗値として扱います。Yellowを含む列だけでなく、Cyan、Magentaおよび混色の列も5%からCMY配合を保持します。5%未満のごく薄い非Yellow色差はWhiteのノイズとして除去します。暗い無彩色と茶色い細線はCyan 1層、Magenta 1層、Yellow 1層、White 4層へ割り当てます。明暗値は全色列で共通の上部White連続高へ変換し、Y100だけが別の高さ段階にならないようにします。0%は顔料なしのWhiteです。

## 色の作り方

Cyan、Magenta、Yellowは減法混色として扱います。

- Green: Cyan + Yellow
- Purple: Cyan + Magenta
- Red: Magenta + Yellow
- 暗色: Cyan + Magenta + Yellow
- White: 顔料なし

標準の色領域7層にCyan、Magenta、Yellow、Whiteを配分すると、120個の整数レシピになります。入力sRGBから求めたCMY被覆量に最も近いレシピを選びます。実際の色は材料の透過率、層数、積層順、光源に依存します。

明暗は主に上部Whiteの厚さで表します。厚い場所ほどバックライトを通しにくく、暗く見えます。材料表示色とチャート配合には指定された明暗値を使い、それ以外の入力色はRec.601輝度を反転して画像内の最小・最大で正規化します。White上面は連続高のまま生成します。0.04 mmは上面メッシュの刻みではなく、Bambu Studioへ渡すスライス層高です。

## 現行の積層構造

モデルは平らな背面をビルドプレート側の`Z=0`に置きます。完成後はバックライトを背面側に置き、凹凸のある`+Z`側から鑑賞します。

```text
+Z / 観察側
┌─────────────────────────┐
│ White: 1.0 mm以上で可変  │  明暗を制御
├─────────────────────────┤
│ CMYWレシピ: 標準7層      │  色相を制御
├─────────────────────────┤
│ White: 下地2層           │  共通の背面
└─────────────────────────┘
Z=0 / バックライト側
```

### 下地のWhite

最初の2層はモデル全体を支える連続したWhiteです。各層は0.1 mmで、平らなバックライト側の面になります。

### CMYWの色領域

下地の上へ、各0.1 mmの色レイヤーを7層置きます。各XYセル・各高さには4材料のどれか一つだけを割り当て、重複や空洞を作りません。

顔料はバックライト側から`Cyan -> Magenta -> Yellow`の順に並び、残りをWhiteが埋めます。`pigment_order`が表すのは3顔料の順序で、Whiteは常にその後です。

| 表現する色 | 色領域7層の例             |
| ---------- | ------------------------- |
| Cyan       | Cyan × 7                  |
| Green      | Cyan × 3 -> Yellow × 4    |
| Purple     | Cyan × 3 -> Magenta × 4   |
| Red        | Magenta × 3 -> Yellow × 4 |
| White      | White × 7                 |

表は代表例で、入力色により層数配分は変わります。暗い無彩色や茶色い細線にはCMYを各1層重ね、残り4層をWhiteにします。

### 明暗を作る上部White

色領域の上を1.0 mmまでWhiteで埋め、その上面を連続高にします。材料表示色と同梱カラーチャートの配合色では指定された明暗値を使い、それ以外の入力色ではRec.601輝度を使います。明るい場所は薄く、暗い場所は厚くします。

`cmy-color-chart.svg`では同じ明暗行にある全13色列を共通のWhite高さへ変換します。YellowのRGB表示色はほかの材料色より明るく見えますが、Y100だけに別のWhite段差は作りません。高さの比較には`preview.png`の見た目ではなく`thickness.png`を使います。

| 領域       | 既定の層数 | Z範囲        |
| ---------- | ---------: | ------------ |
| 下地White  |          2 | 0.00–0.20 mm |
| CMYW色領域 |          7 | 0.20–0.90 mm |
| 上部White  |       可変 | 0.90–2.14689422 mm |

標準の最小厚さは1.0 mm、最大厚さは2.14689422 mmです。

## 材料別メッシュの関係

材料ごとの形状は、共通座標にある互いに重ならない閉じたメッシュです。Whiteは必ず含まれ、使わないCyan、Magenta、Yellowは省略されるため、3MFの材料部品数は1〜4個です。

Bambu Studioでは一つの親オブジェクトの材料部品として扱います。部品を個別に移動、整列、拡大縮小、結合すると位置関係が壊れます。

## 積層構造の比較結果

4層／5層は比較用に指定できます。標準構造は7層の`Cyan -> Magenta -> Yellow -> White`です。

| 項目   | 標準構造                  | 比較可能な代替構造        |
| ------ | ------------------------- | ------------------------- |
| 色領域 | 7層                       | 4層または5層             |
| 顔料順 | Cyan -> Magenta -> Yellow | Yellow -> Magenta -> Cyan |
| 下地   | White 2層                 | White 2層                 |
| 上部   | 可変厚のWhite             | 可変厚のWhite             |

`--color-layer-count`と`--pigment-order`で比較構造を再生成できます。これは目視による発色バランスの採用結果であり、測色校正の結果ではありません。

## 現在の制約

- 未校正時のレシピはフィラメントの実測透過率を使わない
- 入力画像と印刷物の測色的一致を保証しない
- `preview.png`は公称色表示で、印刷物の測色予測ではない
- プリンタ、ノズル、フィラメントロット、光源が変わると発色も変わり得る

測色的一致が必要な場合だけ、[色校正](calibration.md)で実測プロファイルを作成してください。

## 3MFに含まれる情報

`lithop.3mf`には材料別メッシュ、材料名・コード・表示色、Bambu Studio向けExtruder対応、共通座標の組み立て情報が含まれます。

プリンタ、ノズル、AMS実スロット、ビルドプレート、温度、速度、スライスプリセットは含みません。[Bambu Studioでの確認と印刷](bambu-studio.md)に従って設定してください。全成果物は[生成物と記録](artifacts.md)を参照してください。
