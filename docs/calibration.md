# 色校正

Lithopの標準構造は、2層のWhite下地、7層のCMYW色領域、連続した上部Whiteで構成されます。未校正出力は材料の表示色を基準にレシピを選ぶため、実際のフィラメント、プリンタ、バックライトを含む測色的一致は保証しません。

目視結果で用途を満たす場合、数値校正は不要です。使用する材料と観察条件で透過色を測り、入力色に近いレシピと明るさに対応する厚みを選びたい場合に、任意の実測プロファイルを使用します。

## 現在の校正片

`lithop calibrate`は画像を変換せず、標準パレットのセルから校正SVGと印刷用3MFを直接生成します。レイアウトの物理サイズは[`examples/cmy-color-chart.svg`](../examples/cmy-color-chart.svg)と同じ140 × 104 mmです。

| 項目 | 現在の仕様 |
| --- | --- |
| 物理サイズ | 140 × 104 mm |
| 配置 | 16列 × 9行 |
| レシピ | `R000`〜`R119`の120種類 |
| White厚み | `W00`〜`W07`の8段階 |
| 標準ノズル | 0.2 mm |
| 第1層／通常レイヤー | 0.1 mm／0.1 mm |
| 色領域 | 7層、`Cyan -> Magenta -> Yellow -> White` |

120レシピは、7層をCyan、Magenta、Yellow、Whiteへ配分できる全組み合わせです。レシピは先頭8行の15列を使い、鑑賞面から見て上段左の`R000`から行優先で並びます。各セルは横8.125 mm、縦約11.111 mmです。

下段の`W00`から`W07`は、全7色層をWhiteに固定して上部Whiteの厚みだけを変えます。現在の標準設定では、総厚は順に1.0、1.16、1.32、1.48、1.64、1.8、2.0、2.14689422 mmです。値は最小・最大厚さと印刷可能なZ境界から算出されるため、厚さ設定を変更した場合は生成された`calibration-profile.json`の`total_thickness_mm`を正本とします。

右端は向き判別用のWhite列で、上端に`TOP`を表示します。下段の未使用セルもWhiteです。`calibration.svg`はパッチID、色、向きを確認する編集可能な配置図です。材料の積層と厚みを持つ印刷データは、同時に生成される`calibration.3mf`です。

## 校正片を生成する

プロジェクトの`config/settings.json`を使う場合は次を実行します。

```sh
bundle exec lithop calibrate
```

別の設定ファイルを使う場合は`--config`、別のプロジェクトへ出力する場合は`--project-dir`を指定します。校正片は7層・`cyan,magenta,yellow`順と、相異なるWhite厚みを8段階生成できる厚さ範囲を要求します。画像用の幅、高さ、余白、配置、ピクセルサイズは使用しません。

`build/<job_id>-calibration/`へ次の5ファイルを生成します。

| ファイル | 用途 |
| --- | --- |
| `calibration.svg` | 140 × 104 mmのパッチ配置、ID、向きを確認する |
| `calibration.3mf` | Bambu Studioで材料、積層、厚みを確認して印刷する |
| `calibration-profile.json` | 材料、光源、測定条件、各パッチの測定値を記録する |
| `manifest.json` | 積層構造、配置、材料数、三角形数を確認する |
| `CALIBRATION_README.md` | 生成時の設定とパッチ配置を確認する |

全ファイルの定義は[校正ジョブのファイル](artifacts.md#校正ジョブのファイル)、コマンドの全オプションは[校正片を生成する](command.md#校正片を生成する)、読み込む設定は[校正片に使う設定](config.md#校正片に使う設定)を参照してください。

印刷前に[Bambu Studioのレイヤープレビュー](bambu-studio.md#レイヤープレビューを確認する)で、単一プレート、White/Cyan/Magenta/Yellowの割り当て、全レイヤー、140 × 104 mmの寸法を確認します。3MFの寸法、レイヤー高さ、材料順は変更しません。

## 測定プロファイルを記入する

生成直後の`calibration-profile.json`は`status: "draft"`の雛形です。次の条件を記録します。

- Cyan、Magenta、Yellow、Whiteの材料ロット
- バックライトの種類、色温度、照度
- 測定方法、機器、測定不確かさ
- 光源だけを測った白点と、遮光時の黒点
- 120レシピとWhite厚み8段階の測定値

各パッチの`measurements`配列へ、同じ条件で測った値を1件以上追加します。反復測定は複数件をそのまま追加できます。

```json
{
  "transmitted_srgb": [0.81, 0.62, 0.35],
  "luminance": 118.4,
  "error": 1.7
}
```

`transmitted_srgb`は0〜1の3要素、`luminance`は0以上、任意の`error`も0以上です。`measurement.white_point`と`measurement.black_point`にも同じ形式の測定値を記録します。条件が変わった場合は値を混在させず、新しい校正ジョブまたはプロファイルとして管理します。

カメラを使う場合は、自動露出、自動ホワイトバランス、HDR、画像補正を無効にし、同じ撮影条件を維持します。カメラ値を測色計の値と同等には扱わず、`measurement.method`と`measurement.device`へ方法と機器を記録します。

## 測定手順

1. `calibration.svg`でパッチIDと向きを確認する。
2. `calibration.3mf`をBambu Studioで開き、材料割り当てと全レイヤーを確認して印刷する。
3. 十分に冷却し、一定のバックライトと周囲光を用意する。
4. 各パッチの中央を測色するか、固定した条件でRAW撮影する。
5. 光源だけの白点と、遮光時の黒点を測る。
6. 測定値を対応するパッチの`measurements`へ追加する。
7. 必要に応じて同じ条件で反復し、材料、光源、機器、誤差を記録する。

## 実測プロファイルを使う

全128パッチと白点・黒点を記入したプロファイルを、通常生成の`--calibration-profile`へ指定します。

```sh
bundle exec lithop image.png \
  --calibration-profile build/<calibration-job-id>-calibration/calibration-profile.json
```

読み込み時には、次の条件を検証します。

- スキーマ版とJSONの形式が正しい
- ノズル径、レイヤー高さ、色領域の層数、顔料順が現在の設定と一致する
- 120レシピが現在のパレットと一致する
- White厚みパッチが相異なる8段階ある
- 全パッチに1件以上の測定値がある
- 白点と黒点がある
- White厚みの測定輝度に差がある

条件を満たさない場合は、通常ジョブを作る前に生成を中止します。

## 実測値の使い方

同じパッチに複数の測定値がある場合、`transmitted_srgb`と`luminance`をそれぞれ平均します。

色レシピは、各パッチの平均`transmitted_srgb`を最大成分で正規化し、入力色から求めたRGB比に最も近いものを120レシピから選びます。この段階では明るさを除いた色成分を比較します。

厚みは、入力のWhite明暗密度0〜1を、White厚み8段階で測った最も明るい輝度から最も暗い輝度までへ線形に対応させ、目標輝度に最も近い段階を選びます。通常画像のWhite明暗密度はRec.601輝度から求め、材料表示色と同梱カラーチャートの配合色では定義済みの明暗値を使います。選択した厚みは現在のレイヤー境界へ丸めます。

選択した同じWhite高さを`lithop.3mf`のWhite形状、`cmyk_white.stl`、材料モデル、`preview.png`、`transmission.png`、`thickness.png`、4材料マスクへ渡します。このため、実測プロファイル適用後の形状と確認画像で異なる厚みを使いません。

使用したプロファイルは通常ジョブへ`calibration-profile.json`としてコピーされ、`settings.json`と`manifest.json`へプロファイルID、元パス、選択方式を記録します。

色レシピと明るさは独立に選択します。レシピごとの明るさの違いや、色と厚みの相互作用を同時に補正する色管理方式ではありません。

## 現在の検証範囲

- 140 × 104 mm、16列 × 9行のSVGと3MFの寸法・配置を自動検証している
- 7層120レシピ、White厚み8段階、向き判別列の生成を自動検証している
- プロファイルの生成、JSON検証、積層条件照合、反復測定の平均、レシピと厚みの選択を自動検証している
- 現行140 × 104 mm校正片の0.2 mmノズルによる実機印刷は完了していない
- 7層120レシピについて、実機での数値測色と色差評価は完了していない
